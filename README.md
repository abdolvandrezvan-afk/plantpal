# PlantPal | گیاه‌یار

برنامه‌ای ساده برای مراقبت و نگهداری از گیاهان.

## درباره پروژه

PlantPal به شما کمک می‌کند گیاهان خود را ثبت کنید،
آبیاری را ثبت کنید و تاریخچه مراقبت را ببینید.

## وضعیت پروژه

در حال ساخت — نسخه ۰.۱.۰

## فناوری‌ها

- HTML
- CSS
- JavaScript
- IndexedDB
- Git

## قابلیت‌های نسخه اول

- ثبت گیاه (نام، نوع، محل نگهداری)
- تصویر گیاه (اختیاری)
- مشاهده فهرست گیاهان
- مشاهده جزئیات گیاه
- ویرایش گیاه
- حذف گیاه
- ثبت آبیاری
- مشاهده تاریخچه مراقبت
- صفحه اصلی
- دوزبانه (فارسی + انگلیسی)

## ۹. ساخت فایل `.gitignore`

### گام ۹.۱ — چرا .gitignore؟

**gitignore.** فایلی است که به Git می‌گوید «این فایل‌ها را نادیده بگیر.» مثلاً فایل‌های موقت، فایل‌های پشتیبان، پوشه‌های اضافی.

### گام ۹.۲ — ساخت فایل در VS Code

1. در VS Code، روی **PLANTPAL** راست‌کلیک کن.
2. **New File**.
3. نام: `.gitignore`
4. **Enter**.

### گام ۹.۳ — محتوا
